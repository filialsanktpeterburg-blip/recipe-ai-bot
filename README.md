# ИИ-бот «Рецепт из холодильника»

Учебный Telegram-бот принимает список продуктов и создаёт пошаговый рецепт с
помощью GigaChat API.

## Что доказывает использование ИИ

Каждое обычное сообщение пользователя передаётся через API в GigaChat. Модель
генерирует новый рецепт, а бот отправляет его пользователю. Команда `/about`
коротко объясняет это прямо внутри бота.

## Что понадобится

1. Telegram-токен, полученный у официального бота `@BotFather`.
2. `Authorization Key` проекта GigaChat API для физического лица.
3. Аккаунт BotHost и репозиторий GitHub с этими файлами.

Токены нельзя добавлять в файлы или публиковать в GitHub. Они задаются в
защищённых переменных окружения хостинга.

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота. BotHost обычно создаёт эту переменную
  автоматически из поля Bot Token.
- `GIGACHAT_CREDENTIALS` — Authorization Key из кабинета GigaChat API.

## Файлы проекта

- `bot.py` — программа бота;
- `requirements.txt` — список библиотек, которые хостинг установит сам;
- `.gitignore` — защита от случайной публикации секретов;
- `ТЕКСТ_ДЛЯ_СДАЧИ.txt` — описание проекта и сценарий проверки.

## Быстрая проверка после запуска

1. Открыть бота и нажать **Start**.
2. Отправить: `картофель, яйца, сыр, лук`.
3. Убедиться, что бот прислал название блюда и пошаговый рецепт.
4. Отправить другой набор продуктов и убедиться, что рецепт изменился.
5. Скопировать ссылку вида `https://t.me/имя_бота` для сдачи.
